# 📚 Online Book Store SQL Analysis

## 📌 Project Overview
This project focuses on analyzing an online bookstore's data using SQL to explore customer behavior, book inventory, sales performance, and revenue trends.

## 🛠️ Tools & Technologies
- MySQL
- SQL

## 🗂️ Database Tables
- **Books:** Book details, genres, prices, and stock.
- **Customers:** Customer information and locations.
- **Orders:** Order dates, quantities, and transaction amounts.

## 🎯 Key Analysis
- Analyzed book sales and inventory.
- Identified top-performing books and genres.
- Analyzed customer spending and purchasing patterns.
- Identified high-value customers and customers with no orders.
- Calculated monthly revenue and cumulative sales.
- Ranked books by revenue within each genre.

## 🧠 SQL Skills Demonstrated
`SELECT` · `WHERE` · `GROUP BY` · `HAVING` · `JOINS` · `Subqueries` · `CTEs` · `Window Functions` · `CASE` · `Aggregate Functions`
